# UGAR_Korean_Font_Patch
Ultimate General American Revolution Korean Font Patch

Ultimate General: American Revolution 비공식 한국어 폰트 패치
독립 실행 시험판 1 / Windows 10·11 64비트


사용 방법
1. 압축파일을 다운로드 폴더 등 새로운 폴더에 풉니다. 게임 폴더에 풀 필요 없습니다.
2. 게임을 완전히 종료합니다.
3. UGAR_Korean_Font_Patch.exe를 실행합니다.
4. 메뉴에서 1(설치), 2(검사), 3(복원)을 선택합니다.
5. '작업이 완료되었습니다' 안내를 확인한 다음 게임을 실행합니다.
   복사와 검사는 시간이 걸리며, 잠시 출력이 없어도 창을 닫지 마세요.

지원 및 범위
분석 대상: Steam Windows v1.0.3, 로그 revision 55378 / version.xml revision 55380.
일치하지 않는 게임 파일은 안전을 위해 설치를 중단합니다.
설치 준비와 백업에 게임 드라이브 약 7GB의 여유 공간이 필요합니다.
현대 한글 음절 11,172자와 자모의 글자 누락(□)을 보완합니다.
오역, 미번역, UI 잘림까지 모두 해결하는 패치는 아닙니다.
누락 글자에는 Noto Serif KR Regular를 사용하므로 기존 글자와 모양이 다를 수 있습니다.

백업과 복원
ugar_Data/UGAR_KoreanFontBackup_public_v1 폴더를 삭제하지 마세요.
3번 메뉴는 이번 공개 패치 설치 직전의 상태로 돌립니다.
게임 업데이트 후에는 오래된 백업을 수동으로 덮어쓰지 마세요.
복원으로 제거된 파일은 별도 폴더에 보관되므로 디스크 공간이 즉시 줄지 않을 수 있습니다.

배포와 검증
원본 게임 파일이나 Windows 맑은 고딕 데이터는 포함하지 않았습니다.
OFL.txt, FONT-NOTICE.txt 및 실행 환경의 라이선스 안내를 함께 유지하세요.
개발사의 공식 패치나 승인된 배포물이 아닙니다.
자동 파일 검증과 독립 실행 검사를 진행한 시험판입니다.
독립 실행 EXE 설치 후 실제 게임 화면 검증은 사용자가 추가로 진행해야 합니다.
서명되지 않은 실행 파일입니다. 보안 프로그램이 차단하면 보안 기능을 끄지 말고
배포 출처와 파일을 확인하세요.
